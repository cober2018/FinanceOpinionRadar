## Why

视频总结的拉取 API 和 Webhook 推送已经实现，但“开放接口”页面只用一段说明文字介绍，操作者难以直接看清可用接口、事件类型、字段和当前订阅情况，也容易把“暂无渠道”误认为“暂无接口”。

## What Changes

- 在“开放接口”页面分别列出已实现的视频总结拉取 API 和推送事件，标明用途、鉴权方式、请求与载荷字段、事件状态及时间口径。
- 在推送事件旁展示当前通用 Webhook 的订阅状态，沿用现有渠道创建、开关和投递记录操作；未配置渠道时仍显示可用接口和事件定义。
- 只展示后端实际支持的契约，不增加接口定义编辑、发布或新的推送协议。

## Capabilities

### New Capabilities

- `video-summary-open-interface-catalog`: 在开放接口控制台集中展示视频总结拉取 API、推送事件及订阅状态。

### Modified Capabilities

None. 当前视频总结控制台规范仍在未归档的变更中；本提案只补充其展示粒度，不改变数据交付契约。

## Impact

主要修改 `apps/web/src/App.tsx` 的开放接口页面与相关 README；复用现有 `/open/v1/video-summaries`、单视频查询、渠道管理和投递记录接口。后端路由、数据库结构与推送任务不变。
